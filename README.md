Starlight Shepherd is a top-down arena shooter: play a lantern keeper fighting waves of wisps, mites, brutes and spitters, chaining combos and picking one of three upgrades after each wave. Plain JavaScript and Canvas, no build step, fully offline.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser (or open game/index.html directly).
